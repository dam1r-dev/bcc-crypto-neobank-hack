# by BCC — демо фронтенда

Мобильный демонстрационный интерфейс на React, TypeScript и Vite по макетам Figma. Данные сохраняются в localStorage браузера; платежи, котировки и операции являются демонстрационными. Серверная часть не подключена.

## Запуск

```bash
npm install
npm run dev
```

Проверка: `npm run lint` и `npm run build`.
