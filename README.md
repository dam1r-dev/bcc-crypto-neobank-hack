# JINABACK by BCC

Кейс BCC Future Talent «Крипто-необанкинг». Самостоятельное мобильное приложение: тенге, золото от 1 000 ₸ и кошельки
партнёров МФЦА в одном портфеле. До покупки видно, сколько останется при продаже.

Все данные в прототипе синтетические. Реальных денег, лицензий, токенов и интеграций нет.

## Что где лежит

| Путь | Что это |
|---|---|
| `front/` | Прототип: Vite + React + TypeScript + Tailwind, сборка в один `dist/index.html` |
| `release/jinaback-offline.html` | Готовая сборка одним файлом. Открывается двойным кликом без интернета (запасной вариант на защите) |
| `docs/00-brief.md` | Бриф кейса и заметки команды |
| `docs/01-product-strategy.md` | Стратегия v2.1: позиционирование, сценарий, бизнес-модель, гипотезы, моки |
| `docs/Crypto Neobank BCC Deep Research …md` | Ревью гипотез и экономики с внешними источниками |
| `docs/BUILD-SPEC.md` | ТЗ на прототип: расчёты, тесты, экраны, критерии приёмки |
| `docs/DESIGN-BRIEF.md`, `docs/DESIGN.md` | Стиль и дизайн-система (Figma) |
| `docs/PROGRESS.md` | Что сделано, что дальше, расхождения со стратегией |
| `CLAUDE.md` | Правила для Claude Code при работе с проектом |

## Запуск

```
cd front
npm install
npm test          # 25 тестов на опорные числа
npm run dev       # разработка
npm run build     # dist/index.html — один файл
```

## Деплой на Vercel

Import репозитория → ветка `Ansar` → Root Directory `front` → Framework Vite → Build `npm run build` → Output `dist` → Deploy.

## Демо на защите

Сценарий: знакомство → пополнение 50 000 ₸ → покупка золота на 10 000 ₸ (0,1600 г, при продаже ≈ 9 800 ₸) →
«Курс обновился» → «Отменить» → покупка → кешбэк граммами → партнёр Vexelia (демо) → главная 59 960 ₸ → «Метрики демо».

Демо-панель: Shift+D, 5 быстрых тапов по верхней середине экрана или `?demo=1` в адресе.
Перед выходом на сцену: демо-панель → «Сброс к онбордингу».
